# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

RediHealth staff, including health workers, mediators, doctors, and administrators, use the panel to manage care requests, patient records, and follow-up work. The public application also provides multilingual health information and access to care.

## Product Purpose

Help staff review requests, find patient records, coordinate appointments, and access the tools needed to provide care. The panel home prioritizes direct request handling, with search, filters, and actions above the request list; existing navigation provides access to other tools.

## Capabilities and Constraints

Preserve existing authentication, role permissions, country context, request filtering, editing, patient creation, exports, appointment tools, and offline and demo runtimes. Use the existing Next.js and React implementation. All new interface text supports English, Romanian, Albanian, Italian, Croatian, Romani, and Russian.

## Brand Commitments

Preserve the RediHealth identity and logo. Emergency red remains reserved for emergency and destructive states; staff actions use sapphire.

## Evidence on Hand

Existing panel components, translated copy, backend request counts, and the browser-local demo with explicitly fictional patient records. Do not invent clinical statistics or claim that demo data is live.

## Accessibility and Inclusion

Preserve keyboard navigation, visible focus, accessible control labels, 44px touch targets, reduced motion, and responsive mobile navigation.
